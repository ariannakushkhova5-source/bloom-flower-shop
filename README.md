# 🌷 Bloom — цветочный магазин

Учебный многостраничный сайт цветочного магазина, созданный в рамках контрольной точки по предмету «Фронтенд-разработка для веб-дизайнеров».

## О проекте

Сайт состоит из трёх страниц с единой навигацией и стилем:

- **index.html** — главная страница с описанием магазина и хитами продаж
- **catalog.html** — каталог букетов с ценами
- **contacts.html** — контактная информация и форма обратной связи

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, CSS-переменные, адаптивная вёрстка)
- GitHub Pages для публикации
